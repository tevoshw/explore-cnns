# 1. Image Classification

## 1.1 VGG (Winner of ImageNet 2014)

It's the classic. An CNN with blocks, gap and FNN, wheres
1. Each block have
- Some Convolution + Normalization + Non-Linearity (Normally this sequence N times) creating a single block (normally have N blocks in a VGG)


```


VGG - Example
Input: (1, 3, 224, 224) batch=1, channels=3, height=224, width=224


#1.
BLOCK 1: (input gonna be (1, 3, 224, 224) )
├─ Conv 3×3 (64 channels, padding=1, stride = 1) → (1, 64, 224, 224)
├─ Normalization
├─ ReLU
- Repet this cycle N times
└─ MaxPool 2×2 → (1, 64, 112, 112)  ← height/width ÷2

So this it's 1 block. Normally its X of this block

# 2.
AdaptiveAvgPool → (1, 512, 7, 7)

# 3.
Flatten + FeedForwardNetwork with the classification layer


```


## 1.2 ResNet (Winner of ImageNet 2015)

It's basically. An VGG with residual connections in the blocks, gap and FNN, wheres
1. Each block have
- Some Convolution + Normalization + Non-Linearity (Normally this sequence N times) creating a single block (normally have N blocks in a VGG). And some  have a residual connection.


```
ResNet - Example
Input: (1, 3, 224, 224) batch=1, channels=3, height=224, width=224


#1.
BLOCK 1: (input gonna be (1, 3, 224, 224) )
├─ Conv 3×3 (64 channels, padding=1, stride = 1) → (1, 64, 224, 224)
├─ Normalization
├─ ReLU
- Repet this cycle N times
└─ MaxPool 2×2 → (1, 64, 112, 112)  ← height/width ÷2
└─(IF YES + RESIDUAL CONNECTION)

So this it's 1 block. Normally its X of this block. And some can have a residual connection

# 2.
AdaptiveAvgPool → (1, 512, 7, 7)

# 3.
Flatten + FeedForwardNetwork with the classification layer


```
